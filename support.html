Support

RanchHub is one dashboard on your own PC that runs your AI assistants as a team, with a stop switch only you hold. It is in beta.

Need help? Email getranchhub@gmail.com with what you were doing, what you expected and what happened. Include the version shown in the app window (for example 0.1.1-beta.3).

Requirements

  • Windows 10 (version 1809 or newer) or Windows 11, 64-bit.
  • A web browser (Edge or Chrome) for the dashboard. Push to talk needs the browser's speech feature.
  • Optional: your own AI accounts. RanchHub does not include an AI subscription.

Common questions

How do I stop everything?
Flip the brake on the dashboard. While the brake is on, no AI can change anything through RanchHub, and nothing is released or sent. Only you can turn it off.
Where is my data?
In one file on your computer, ranchhub-data.json. The dashboard shows its full path on the "Data file" line. Nothing is stored online by RanchHub. See the privacy policy.
How do I back up or move RanchHub?
Copy the data file (and the audit log and ledger beside it, if present) to the new computer's data folder before the first start. Copying a file into a running RanchHub is not supported; close it first.
How do I uninstall?
Settings → Apps → RanchHub → Uninstall. Your data file stays in your user folder so you can keep or delete it.
What is the Clean Exchange?
A check on notes passing between your AI team and an outside AI (for example your employer's). It blocks clearly sensitive items, holds anything doubtful for you to release or reject, and writes an audit line (types and rule names only, never contents) for your IT department.
The dashboard page does not open.
Keep the RanchHub window open; closing it stops the app. Then open the address it printed (it starts with http://127.0.0.1:). If a security tool blocks it, allow RanchHub on local connections only – it never listens on your network.
Talk to Bex says "not set up".
It needs your own Anthropic API key, saved as described in the app's README. Without a key the tab sends nothing. Each reply shows its cost; the hub stops calling the API once the month's total reaches the limit you set in Anthropic's Console.
Is there a Mac or Linux version?
Windows first. Mac and Linux builds exist for testing and will follow once the Windows version is stable.
